# Deviations from the frozen protocol

Protocol frozen: 2026-07-29

Every departure below was decided BEFORE any federated run existed.

| Date | Deviation | Justification |
|---|---|---|
| 2026-07-29 | Grid backbones changed from {DistilBERT, BERTweet, PubMedBERT} to {RoBERTa-base, BERTweet, PubMedBERT}; DistilBERT demoted to appendix continuity runs. | DistilBERT is 6 layers / 66M against 12 layers / ~110-125M for the other two, so pretraining domain would have been confounded with model capacity across the grid. All three backbones are now base-scale and trained from scratch on a domain corpus, leaving domain as the only systematic difference. |
| 2026-07-29 | Tertiary alignment measure changed from embedding-centroid distance to subword fertility + vocabulary coverage, both reported descriptively rather than blended in. | Centroid distance requires a pretraining-corpus sample, unavailable for BERTweet and PubMedBERT. Coverage is ~1.000 in every cell and fertility varies under 5% within a backbone, so z-scoring them gave noise the same weight as a 300x perplexity range. |
| 2026-07-29 | Alignment score is the TWO-WAY-centred (backbone x dataset) interaction in log per-word perplexity, not a within-backbone z-score composite. | Token perplexity is not comparable across tokenizers (fixed by per-word conversion). Centring on the backbone axis alone removes model capacity but leaves corpus difficulty: Sentiment140 is the hardest corpus for EVERY backbone, so each backbone appeared best-aligned to the easiest corpus. Two-way centring isolates the interaction, which is the definition of domain alignment. |
| 2026-07-29 | The diagonal calibration result in Section 4.1 is NOT reported as evidence for H1. | The normalisation was chosen after inspecting the alignment matrix. It validates the instrument, not the hypothesis. H1 is tested only by the pre-registered endpoints: sign agreement at gate G1 and Spearman rho >= 0.6 at gate G2, both computed from federated results that did not exist when the normalisation was fixed. |
| 2026-07-29 | Primary endpoint changed from client-local macro-F1 (P1) to client-class macro-F1 on the global test set (P3). P1 retained and co-reported as deployment utility. | P1 is maximised by a constant local-prior predictor when a client holds a single class, since precision is 1 by construction on a single-class test split, so it rewards collapse under extreme skew. P3 scores on the full global test set where out-of-class false positives are punished. All three metrics are logged every round, so either choice is recomputable from results.jsonl without re-running anything. |
| 2026-07-29 | Appendix controls (full-size, K=50, natural partition, LoRA rank) moved from DistilBERT to RoBERTa-base. | A control run on a backbone absent from the main grid controls for nothing. FedAvgW and the DistilBERT alpha runs stay on DistilBERT because their purpose is explicit continuity with the accepted paper. |
| 2026-07-29 | Scope reduced to fit the measured compute budget: alpha sweep cut to one extra level on diagonal cells, SCAFFOLD and q-FedAvg dropped, method candidates on the diagonal only, appendix at 2 seeds, 30 rounds instead of 40. | Measured cost on a T4 exceeded the available Pro+ allocation. Cuts were chosen to protect the 3x3 grid, 5 seeds throughout, the 10-seed primary endpoint, and the matched-capacity backbone set - i.e. everything that carries a claim. |

| 2026-08-02 | G2 evaluated at n=9: rho=0.617, p=0.0769. Pre-registered criterion (protocol section 8: rho>=0.6 AND p<0.05) NOT met; H1 as specified is not supported. | The section 10 gate table lists only rho>=0.6; the stricter section 8 criterion is treated as binding. Primary discordant cell is PubMed x RoBERTa (predicted harmful, observed +0.140, Holm p=0.037), whose absolute per-word perplexity on PubMed (44.9) is second-lowest in the grid. |
| 2026-08-02 | H2b (representational hypothesis) falsified. Local-only worst-client effects are large and negative in all 5 cells (Cliff's delta = -1.00 throughout); diagonal-vs-corner contrast -0.096. | Alignment confers no worst-client advantage absent aggregation. Neither adapter interference (H2) nor frozen-representation transfer (H2b) explains the effect. Phase 2 candidates A/B/C are cancelled: all three defend against interference that is not occurring. |
| 2026-08-02 | EXPLORATORY: within each dataset, backbone ordering by RAW per-word perplexity matches worst-client effect ordering in 3/3 datasets (p~0.005); across 9 cells rho=0.867. NOT adopted as confirmatory. | Raw perplexity is confounded with dataset difficulty via baseline headroom, which is why the predictor was two-way centred. Recorded as exploratory and tested out-of-sample below. |
| 2026-08-02 | PRE-REGISTERED out-of-sample predictions, committed before the corresponding runs execute: (1) DistilBERT x AG News (per-word PPL 76.6) effect will fall between +0.017 and +0.111; (2) the within-dataset perplexity ordering will hold for at least 3 of 4 non-FedAvg algorithms at p40; (3) effect magnitude will increase at alpha=0.05 relative to alpha=0.1. | Converts the exploratory perplexity finding into a falsifiable claim testable on runs already in the manifest. |
